**To test the RF Switch**

Using a VNA calibrated to the magnets working frequency, go through the following combinations in reflection and transmit mode. All components not being tested at a given moment need to be connected to a 50 Ohm load.

| **Reflection (S11/S22 on VNA)** | Signal Source | E.g. Working active switch | Your switch |
| --- | --- | --- | --- |
| Transmit mode (Switch ON)   | Tx | -23 |  |
| Transmit mode (Switch ON)   | Coil | -21.2 |  |
| Receive mode (Switch OFF)   | Coil | -22.9 |  |
| Receive mode (Switch OFF)   | Rx | -22.4 |  |
| **Transmission (S12/S21 on VNA)** | **T - R** |  |  |
| Transmit mode (Switch ON)   | Tx - Coil | -0.24 |  |
| Transmit mode (Switch ON)   | Tx - Rx | -39.5 |  |
| Transmit mode (Switch ON)   | Coil - Rx | -40.4 |  |
| Receive mode (Switch OFF)   | Tx - Coil | -53.4 |  |
| Receive mode (Switch OFF)   | Tx - Rx | -50 |  |
| Receive mode (Switch OFF)   | Coil - Rx | -0.21 |  |
