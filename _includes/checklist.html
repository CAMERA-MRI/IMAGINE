10 / 17 OSI² Hardware Score

OSI² CAB Review Checklist

This checklist tracks compliance with the Open Source Imaging Initiative (OSI²) hardware documentation best practices. It helps ensure that researchers and engineers globally can replicate the scanner designs reliably.

1. Readme & Documentation

  • README File Available (1 point) Project description is clearly documented in the repository.
  • Design Considerations Explained (1 point) Detailed design objectives, bore diameter, and magnet configurations are explained.

2. Bill of Materials

  • BoM Provided (1 point) BOM files are available with complete lists of electronic, RF, and magnet components.
  • BoM Best Practices Compliant (1 point) Includes links to DigiKey/Amazon, pricing estimation, and vendor references.

3. Source & Native CAD Files

  • Native Source Files Available (1 point) Autodesk Inventor (.ipt, .iam) and CAD source files are available in the repository.
  • Editable with Open-Source Software (1 point) Files are exportable and editable in FreeCAD / OpenSCAD, and circuits in KiCAD.

4. Production & Fabrication Files

  • Accessible Exports Available (1 point) STEP/STP and 3D printing STL files are provided for direct printing of the magnet rings and RF coil.
  • Manufacturing Environment Defined (0 points) Specific machine/printer settings (infill, filament types, layer height) are currently undefined.

5. Assembly Guidance

  • Assembly Guide Available (1 point) Step-by-step instructions are provided, supplemented by assembly guide animation videos.

6. Development Tracking & Community

  • Versioning Scheme Implemented (1 point) A GitHub Git repository tracks all design changes and history.
  • Public Issue Tracking (0 points) GitHub Issues are not yet utilized actively for bug reports and enhancements.
  • Public Communication Space (0 points) A forum, Slack/Discord workspace, or open email list is not yet linked for developer-user exchange.

7. Testing & Verification

  • Testing Routines Available (1 point) Calibration procedures are provided, such as RF Switch VNA measurements and RF Coil tuning guides.
  • Testing Routines Complete (0 points) Detailed testing guides for the control system enclosure and GPA-FHDO are still in development.

8. Use & Safety

  • User Manual (0 points) A complete end-user manual for running preclinical scans is not yet published.
  • Risk Assessment & Safety Notice (0 points) Safety notices concerning high magnetic fields (B0) and RF power have not yet been formalised.
  • Replication History Documented (1 point) Success stories of independent builds (ERNIE 1 and ERNIE 2) are documented in detail.
