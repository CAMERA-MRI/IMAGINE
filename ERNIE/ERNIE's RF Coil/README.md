## RF Coil Design and Specifications

The ERNIE low-field MRI scanner uses a solenoid RF coil for radiofrequency excitation and signal reception. The coil is constructed using 18 AWG copper wire with 18 turns.

### RF Coil Specifications

| Parameter | Specification |
|---|---|
| RF coil type | Solenoid |
| Coil height | 90 mm |
| Outer radius | 22 mm |
| Inner radius | 20 mm |
| Number of turns | 18 |
| Wire gauge | 18 AWG |
